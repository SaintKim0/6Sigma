## 이미지 파일 위치

- 디자인 원본: `marketing/instagram/index.html` (브라우저로 열기)
- PNG export: `marketing/instagram/export/` (스크립트로 생성)

## 릴스 MP4 (완성본)

경로: `marketing/instagram/export/reels/`

| 파일 | 내용 | 길이 |
|------|------|------|
| `reel-a-app-intro.mp4` | 엑셀만으로? → 앱 실습 → DMAIC·DFSS → CTA | ~15초 |
| `reel-b-dmaic-dfss.mp4` | 개선/설계 분기 → DMAIC → DFSS → CTA | ~15초 |
| `reel-c-before-after.mp4` | 흩어진 문서 → 한곳 도구 → CTA | ~15초 |

- 해상도: **1080×1920 (9:16)** · H.264 · 무음 (인스타에서 음악 추가)
- 캡션: 위 섹션 2~4 복붙
- 커버 PNG: `export/reel-a-cover.png` 등 (업로드 시 커버로 지정 가능)

다시 만들기:

```bash
node marketing/instagram/render-reels.mjs
```
